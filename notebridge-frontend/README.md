# NoteBridge Frontend

Professional React + TypeScript + Vite + Tailwind CSS frontend prototype aligned with the NoteBridge proposal.

## Run
```bash
npm install
npm run dev
```

## Included
- Verified student login screen
- Responsive dashboard
- Course hierarchy browsing
- Resource search/listing UI
- Community Q&A
- Upload resource screen
- My Library/bookmarks
- AI summary + quiz UI
- Professional responsive sidebar/header

The screens currently use mock data. Connect the existing FastAPI endpoints for authentication, resources, ratings, notifications, AI, and Q&A.
